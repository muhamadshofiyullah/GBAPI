# GB Web API & Dashboard

Aplikasi pengelola transaksi dan jembatan otomatisasi untuk layanan pembayaran **GB** (PLN, Pulsa, PDAM, BPJS dan pembayaran tagihan lainnya). Dilengkapi dengan antarmuka web (dashboard) yang modern, rapi, dan sangat mudah digunakan.

---

## 🌟 Fitur Utama

- **💳 Cek & Bayar Tagihan (Inquiry & Payment)**

- **📊 Dashboard Transaksi yang Jelas**

- **🖨️ Cetak Struk Pembayaran**

- **📈 Rekap & Laporan Transaksi**

- **⚙️ Pengaturan Mudah Lewat Web**

- **🔒 Keamanan & Perawatan Otomatis**:
  - **Kunci Akses Komputer (Whitelist IP)**: Anda dapat membatasi agar aplikasi hanya bisa dibuka dari komputer/perangkat tertentu yang didaftarkan.
  - **Pembersihan Otomatis**: Riwayat log transaksi lama (lebih dari 60 hari) akan dibersihkan secara otomatis agar aplikasi tetap ringan dan tidak membuat memori komputer penuh.
  - **Bantuan Login Otomatis**: Dukungan pemecahan kode keamanan (captcha) otomatis saat masuk ke akun.

---

## 💻 Panduan Penggunaan Singkat

### 1. Menjalankan Aplikasi
- Cukup klik dua kali pada file `griyabayar.exe`.

### 2. Membuka Halaman Dashboard
Buka peramban web (Google Chrome, Microsoft Edge, atau browser lainnya), lalu ketik alamat:
```
http://localhost:50001
```

---

## 🧭 Menu yang Tersedia

1. **Dashboard (Transaksi)**: Halaman utama untuk memantau ringkasan saldo, angka transaksi, dan tabel data transaksi yang sedang berjalan.
2. **Cetak Struk**: Halaman untuk mencari data transaksi lalu mencetak struk transaksi untuk pelanggan.
3. **Laporan**: Halaman untuk melihat mutasi.
4. **Produk**: Daftar seluruh produk tagihan dan pembayaran yang didukung beserta kode produknya.
5. **Pengaturan**: Halaman untuk mengatur preferensi aplikasi.

---

- Pastikan komputer terhubung ke internet saat menjalankan aplikasi agar dapat bertukar data dengan server GB.
- Jika tampilan halaman web belum berubah setelah update, lakukan **Refresh** halaman dengan menekan tombol **Ctrl + F5** di keyboard komputer Anda.
